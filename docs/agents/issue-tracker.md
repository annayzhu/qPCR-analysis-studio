# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues:

- Repository: `annayzhu/qPCR-analysis-studio`
- Pull requests as a request surface: no

Use the authenticated GitHub connector when available. The `gh` CLI may be used when it is authenticated.

## Conventions

- Publishing a specification means creating a GitHub Issue.
- Read the complete issue body, labels, and comments before implementation.
- Apply the repository triage labels defined in `triage-labels.md`.
- Add implementation findings or blocked conditions as issue comments.
- Close an issue only after its acceptance criteria are verified.
- Pull requests and issues share one number space; resolve the object type before updating it.
