# Triage Labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer review is required |
| `needs-info` | `needs-info` | Waiting for additional information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for implementation |
| `ready-for-human` | `ready-for-human` | Requires direct human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When an engineering skill names a canonical role, use the corresponding GitHub label in this table.
